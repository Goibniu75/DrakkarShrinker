Drakkar Shrinker
A small BepInEx plugin for Valheim that uniformly scales the vanilla Drakkar (VikingShip_Ashlands) to 65% of its usual size. Its visual model and physics colliders scale together.

Default scale is 0.65 (65%).
This mod does not alter Drakkar durability, speed, inventory slots, or Ashlands-water protection.
Extremely small values can make boarding and interactions awkward, so the configuration intentionally has a 25% minimum.
